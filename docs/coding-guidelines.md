# Coding Guidelines

## General Principles

- **Avoid coupling between components** — keep components independent and loosely coupled to improve modularity and testability
- **KISS (Keep It Simple, Stupid)** — prefer simple, straightforward solutions over complex ones; write code that is easy to read and understand
- **Use design patterns when they improve understanding** — apply recognized design patterns where they add clarity and structure, but avoid forcing them when a simpler approach suffices
