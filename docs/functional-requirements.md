# Functional Requirements

## Task Management

### FR-1: Add Due Date to Tasks
Users can add a due date when creating a task.

### FR-2: Edit Tasks
Users can edit an existing task's details, including its name and due date.

### FR-3: Sort Task List
The task list can be sorted by:
- **Due date** – tasks ordered chronologically by their due date
- **Name** – tasks ordered alphabetically by their name
